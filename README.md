# Miniguia-engsoftware-notebooklm
Notebooklm criado para auxiliar os estudos em engenharia de software, e metodologias ágeis.

# Objetivos 
- Auxiliar o processo de aprendizado de engenharia de software.
- Auxiliar aprendizado de metodologias ageis no desenvolvimento de software
- Testar estratégias de prompt engineering
- Avaliar a qualidade das respostas geradas
- Construir um guia de revisão reutilizável
